관리자 로그인

GitHub 접근 토큰으로 로그인합니다.
토큰은 이 브라우저에만 저장됩니다.

토큰 만드는 방법
  1. GitHub 로그인 → 오른쪽 위 프로필 → Settings
  2. 왼쪽 맨 아래 Developer settings → Personal access tokens → Fine-grained tokens → Generate new token
  3. Token name: casavano-admin, Expiration: 원하는 기간 (최대 1년)
  4. Repository access: Only select repositories → casavano
  5. Permissions → Repository permissions → Contents: Read and write
  6. Generate token → 표시된 토큰을 복사해서 위에 붙여넣기

토큰은 비밀번호와 같습니다. 다른 사람에게 공유하지 마세요.
